# 要件

何を・なぜ。手段は [ADR 3 本](adr/)。

## 問題・ユーザー

手作業: トレンド調査 / 重複確認 / 有用論文の発見 / **次のテーマ候補**。

- 論文を書く研究者。未公開データ・原稿を手元に持つ
- **Zotero 利用は前提**。分野非依存。配布する（`C-02`）

## 成功条件（初版）

1. アプリ未起動でも日次で新着候補が溜まる
2. 起動すると重複・活用可能性の報告が読める
3. 関連論文を Zotero に保存できる
4. 執筆中原稿の主張を検査できる
5. 外部 LLM を統制下で呼べる（**利用自体が目的**。ゲートウェイは ADR-0002）
6. 新着から次のテーマ候補を提示できる

やらない: 全分野完全網羅 / クラウド完結の研究環境 / 外部 LLM ゼロを既定
