# 目標と背景

## 問題

研究を進めるとき、次を毎回手作業でやっている。

- 最新の研究トレンドを調べる
- 自分の研究と内容が被っていないか確認する
- 自分の研究に使えそうな論文を見つける
- 最新の研究から次のテーマ候補を見つけてくる

手が回らないと取りこぼしや重複研究のリスクが上がる。

## 対象ユーザー

- 論文を書く研究者（個人または小規模チーム）
- 未公開の実験データ・原稿・メモを手元に持つ
- 参考文献管理に **Zotero を使う**（任意ではなく前提）
- 分野は特定しない（どの分野のどの論文を書くときにも使えること）

配布して他人にも使ってもらうことを前提とする（制約 `C-02`）。

## プロダクトが達成すること

公開論文の流れを自動で追い、自分の研究文脈と照合し、
次のテーマ候補の提示・参考文献の保存・執筆中原稿の事実確認までを
一つの流れで支援する。

あわせて、文章生成・判定のために **外部の LLM を使うこと自体が目的に含まれる**。
未公開データを扱う場合でも、経路と同意が分かる形で安全に呼べること
（`C-03` / `C-04`）。どのゲートウェイ製品を使うかは ADR（現状 ADR-0007）。

## 成功条件

次を満たせば初版として成功とみなす。

1. アプリを起動していなくても、日次で新着論文の候補が溜まる
2. 起動すると、自分の研究との重複・活用可能性が分かる報告を読める
3. 関連論文を Zotero に参考文献として保存できる
4. 執筆中原稿の主張を、手元の文献・新着と照合して検査できる
5. 外部 LLM を、統制された経路・同意の下で呼べる（未公開データを含む用途でも）
6. 新着から、次に追うテーマ候補を提示できる

未公開データの恒久外部インデックス禁止など、破ってはいけない条件は
成功条件ではなく制約（[02-constraints.md](02-constraints.md)）に置く。

## 意図的に含めない価値

「すべての分野の全論文を完璧にカバーする」「クラウドだけで完結する
研究環境にする」「外部 LLM を一切使わない」は目標にしない。
詳細は [04-out-of-scope.md](04-out-of-scope.md)。
