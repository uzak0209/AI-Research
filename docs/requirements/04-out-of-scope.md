# スコープ外

ゴールの「意図的に含めない価値」に対応。

| 項目 | 理由 |
|---|---|
| 全分野・全ソースの初回完全網羅 | アダプタで拡張（`C-05`） |
| クラウドだけで完結する研究環境 | `C-01` |
| 外部 LLM を一切使わないことを既定にする | ゴール上、外部 LLM 利用は目的に含まれる。オプトアウトは `C-03` |
| Overleaf 等への専用クラウド橋 | ローカル同期フォルダ監視で足りる |
| 開発者 LLM キーのアプリ同梱 | `C-06` |
| 未公開データの埋め込みを外部へ全件送信して索引化 | `C-01` |

候補機能は [06-feature-candidates.md](06-feature-candidates.md)。
