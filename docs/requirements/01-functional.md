## FR-01 日次の論文収集とトレンド把握

アプリ未起動でも、毎日公開論文の新着が収集・整理され、後から確認できる。

- 収集は PC 起動に依存しない
- 履歴として残り、起動時に未確認分を取り込める
- 「新着無し」と「取得失敗」を区別できる（`FR-08`）

## FR-02 自分の研究との重複・活用可能性の報告

新着について、自分の研究と被っていないか・活用できそうかを報告として読める。

- 研究文脈（キーワード・概要・手元データ等）を踏まえる
- 粗い候補と精密判定を分けてよい

## FR-03 研究データの検索

未公開の実験データ・ノート・メモ・書きかけ原稿を検索し、判定の根拠に使える。

- 索引の作り方は `C-01` に従う

## FR-04 原稿のファクトチェック

執筆中原稿の主張を、最新論文・手元文献と照合して検査できる。

- 手動実行は必須。定期は未決（`OQ-01`）
- 未公開原稿を外部へ出すときは `C-03` / `C-04`
- 形式は `FR-07`

## FR-05 Zotero への参考文献保存

関連論文を本人の Zotero ライブラリへ保存できる。Zotero 利用は前提（ゴール）。

- 初回接続はブラウザ許可（OAuth）で行える（ADR-0015）
- 手動キーは退避。保存はローカル API 優先（ADR-0014）

## FR-06 複数プロジェクト・分野横断

分野・論文プロジェクトを切り替えられ、過去資産が消えない（`C-05`）。

## FR-07 原稿の取り込み

Markdown / LaTeX / Typst を扱え、ローカル監視と手動追加ができる。

## FR-08 障害と欠損の可視化

収集や判定の欠落を成功と偽らない（`C-07`）。

## FR-09 次の研究テーマ候補の提示

新着・トレンドから、次に追うテーマ候補を得られる（成功条件 6）。

- 公開論文の流れと研究文脈の両方を踏まえる
- 論文紹介で終わらずテーマ粒度で示す
- 詳細 UI は `OQ-05`。手段は ADR-0016

## FR-10 外部 LLM の統制された利用

トレンド解析・判定・ファクトチェック・テーマ候補などで外部 LLM を使える。
**外部 LLM 利用自体がプロダクト目的に含まれる**（ゴール）。

- `C-03` / `C-04` / `C-06` に従う
- ゲートウェイ選定は ADR-0007
