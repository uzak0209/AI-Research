# ADR-0002: 外部 LLM・BFF・データ分類

- **ステータス**: 承認済み / **日付**: 2026-09-19（改訂 2026-09-20: 関連度の採点を対象外に／同日: 29行目の陳腐化した「競合／重複はローカル LLM」記述を訂正／改訂 2026-09-21: 書誌補完は Jev／同日再改訂: 公開書誌は Orca 安価モデル／**同日: TypeSafe Jev を製品から外す。同一論文かは DOI の機械照合で足り、専用判定モデルは置かない**／同日: 認証上流を Google OAuth に変更）
- **要件**: FR-10, FR-12, C-02, C-03, C-04, C-06, C-09, NFR-04

## 決定

外部 LLM 利用自体がプロダクト目的に含まれる（成功条件 5）。

**ただし論文の関連度の採点は対象外。**採点はローカル推論で完結し（`C-09`, ADR-0001）、
BFF に採点用 endpoint を作らない。生成 LLM が担うのは **C1 トレンド要約、C1 公開書誌の穴埋め、テーマ候補（C2）、ファクトチェック（C3）**。

公開書誌の穴埋めは **Orca の安価モデル**に構造化出力させる。対象は利用者が参考文献として置いた**公開文献**だけ。原稿・主張・ノート・注釈は載せない（`C-01`）。OpenAlex からコピーして Jev で同一論文かを切る経路は採らない。

同一論文かの判定に専用モデルは置かない。DOI があれば正規化して文字列一致で足りる。DOI が無ければ候補の中から「同じ論文」を切らず、ヒントと 1 ページ目から書誌を生成する。取り違えは利用者が直す。

```
Electron ──(Google OAuth+PKCE)──→ BFF ──(Workers Secrets)──→ OrcaRouter ──→ 上流
                                              └──────────────→ OpenAlex（日次収集。書誌補完の本線ではない）
```

- **生成 LLM** は OrcaRouter。キー `cron` / `interactive` / `sensitive`。クライアントに置かない
- **TypeSafe Jev は使わない。** `JEV_API_KEY` を製品の前提にしない。noul / choice のための別基盤を置かない
- 機能ごと endpoint。自由プロキシ禁止。監査に本文を残さない。経路はコードが決める（`hono-jev-router` は使わない）
- ゲートウェイゼロ保持は自社のみ → 「残らない」と説明しない

| | C1 | C2 | C3 |
|---|---|---|---|
| 用途例 | トレンド（Orca）／**公開書誌の補完**（Orca 安価モデル・構造化出力） | **テーマ候補**（既定） | ファクトチェック |
| モデル | トレンドは明示 fallback。書誌は `ORCA_POLICY.C1`（安価固定。無料 stealth プールは使わない） | 許可リスト | **固定・FB無効** |
| 同意 | 不要 | 初回 | プレビュー必須。範囲を偽らない |
| その他 | 全滅は 502。分類は BFF のコードが決める。形式不正・title も doi も空は null（C-07） | | 機能ごと完全オフ可。`fail_open: false` |

### 公開書誌に出してよいもの

C1。同意は不要。`references/` に置くことが参考文献としての明示（ADR-0003）。

- ローカル抽出のヒント（タイトル・著者・年・DOI・会場・URL）
- PDF 1 ページ目から取ったテキスト（公開文献の書誌を拾うため）
- 返却は `bibliographyRecordSchema`（タイトル・著者・年・DOI・URL・会場・要旨・`item_type`）

出さない: 原稿、提案手法、ノート、注釈、PDF 原本のバイト（クラウドに置かない。ADR-0003）。採点用の手元論文（`C-09`）。

DOI がスキーマに合わない値、年が範囲外の値は項目を null にする。title も doi も空の応答は補完失敗であり、成功と偽らない（`C-07`）。

分類は BFF が機能で決める。新機能は分類決定後に endpoint。
**関連度の採点・順位付け（FR-02）はローカル推論のみで完結する**（ADR-0001。生成 LLM は使わない）。採点材料の手元論文を BFF に載せない。

却下: キー同梱 / ゼロ保持 alone で C3 許可 / **採点 endpoint を BFF に置く**（`C-09`） / **原稿・ノート・注釈を書誌 endpoint に載せる** / **書誌に無料 stealth プールを使う** / **同一論文判定のために TypeSafe Jev を残す** / **HTTP 経路を意味で振る**（`hono-jev-router`。分類は BFF のコード。Bearer・本文を経路判定で外に出さない）
