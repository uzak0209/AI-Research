# ADR-0007: LLM 呼び出しを OrcaRouter ゲートウェイ経由に統一する

- **ステータス**: 承認済み
- **日付**: 2026-09-19

## コンテキスト

ゴール成功条件 5: **外部 LLM を統制された経路・同意の下で呼べる**。
ゴール本文どおり、外部 LLM 利用は「ついで」ではなく **プロダクト目的に含まれる**（`FR-10`）。

LLM が必要な箇所:

| # | 用途 | 成功条件 | データの性質 |
|---|---|---|---|
| 1 | 日次トレンド解析 | 1 | 公開論文（C1） |
| 2 | 重複・活用の精密判定補助 | 2 | 準機密〜（C2） |
| 3 | テーマ候補の生成 | 6 | 主に公開＋プロフィール（C1/C2） |
| 4 | 原稿ファクトチェック | 4 | 未公開原稿（C3） |

各プロバイダ SDK 直叩きだと認証・フェイルオーバー・コスト把握・ガードレールが分散する。
ゲートウェイに寄せることで、成功条件 5 の「統制」を実装できる。

## 決定

**すべての LLM 呼び出しを OrcaRouter 経由に統一する。** プロバイダ SDK は直接呼ばない。

- エンドポイント: `https://api.orcarouter.ai/v1`（OpenAI 互換）
- 認証: API キー。クライアントには置かない（`C-06`、ADR-0008）

### スコープ付きキー

| キー | 用途 | 特性 |
|---|---|---|
| `cron` | 日次トレンド等（公開） | 日次予算に合わせる |
| `interactive` | ユーザー操作の判定・テーマ候補 | BFF でユーザー単位制限 |
| `sensitive` | 未公開を含む処理 | モデル固定・ガード厳格（ADR-0010） |

### ルーティング

- 公開のみ: 自動選択・フォールバック可（コスト最適化）
- 未公開を含む: `use: { model: ... }` で固定。フォールバック無効（ADR-0010）
- チャネル固定（物理経路）は現状未提供 → 前提にしない

## 検討した代替案

**各社 SDK 直叩き** — ゲートウェイ活用という目的に逆行。却下（障害時退避は ADR-0011）。

**自前の薄い抽象** — ゲートウェイの再実装になる。却下。

## 帰結

**良い点**: 成功条件 5 を一つの経路で実現。コスト・ガードレール・用途分離。

**悪い点**: 単一障害点（ADR-0011）。全プロンプトがゲートウェイ通過 → ADR-0010 必須。
ゼロデータ保持はゲートウェイ自社のみ（上流は別ポリシー）。
