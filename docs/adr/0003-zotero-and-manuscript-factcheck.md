# ADR-0003: Zotero と原稿ファクトチェック

- **ステータス**: 承認済み / **日付**: 2026-09-19
- **要件**: FR-04, FR-05, FR-07, C-03, C-04

## 決定

### Zotero（成功条件 3）

- **保存主経路**: ローカル API `127.0.0.1:23119`（デスクトップ起動時）
- **副**: Web API。資格情報は OAuth 1.0a（Client Secret は BFF）。手動キーは退避
- 取得キーは OS secure storage。**保存トラフィックは BFF に通さない**
- 不通時はローカルキュー（ADR-0001 の障害方針）

### 原稿・ファクトチェック（成功条件 4）

- 形式アダプタ: `.md` → `.tex` → `.typ`（優先順）。ローカル監視＋手動投入。Overleaf 専用橋は作らない
- パイプライン: **抽出 LLM（セクション投入・安価モデル固定）→ ローカル RAG → 検証 LLM（主張ごと・高性能固定）**
- C3。auto ルーティング禁止。同意でセクション送信を正確に示す。「主張のみ」と偽らない
- Typst パーサは供給リスクあり → アダプタ疎結合、最悪行ベースへ

却下: Zotero 保存を常時 BFF 経由 / Overleaf git bridge / 機械抽出のみを本線
