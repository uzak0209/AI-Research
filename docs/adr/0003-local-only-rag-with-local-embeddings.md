# ADR-0003: RAG はローカル完結とし、埋め込みもローカルで推論する

- **ステータス**: 承認済み
- **日付**: 2026-09-19

## コンテキスト

ゴール上、利用者は未公開の実験データ・原稿・メモを手元に持つ。
成功条件 2・4 のため、それらを検索可能にする必要がある（`FR-03`）。
制約 `C-01`: **未公開データの恒久的な外部インデックスを作らない**。

RAG の工程のうち外部送信が起きうるのは埋め込み生成のみ。

## 決定

**RAG を全工程ローカルで完結させる。**

- **埋め込み生成**: ローカルモデルを Transformers.js (ONNX Runtime) で実行する。埋め込み API は使わない
  - 第一候補: `Xenova/multilingual-e5-large`
  - 代替: `Xenova/bge-m3`
  - 初回のみモデル取得、以降オフライン可
- **ベクトル DB**: LanceDB をローカルファイルとして持つ
- 研究データの恒久インデックスをクラウドに作らない（`C-01`）

### 適用範囲（重要）

禁じるのは「未公開データの恒久的なインデックスを外部に作ること」。
都度の LLM プロンプト送信まで禁じてはいない（成功条件 5、`C-04`、ADR-0010）。

| | 埋め込み API | LLM プロンプト |
|---|---|---|
| 送る量 | 全件・網羅的 | 都度・必要範囲（機能により異なる） |
| 外部に残るもの | 恒久インデックスになりうる | リクエスト（上流ポリシー依存） |
| ゴールとの関係 | 成功条件の前提を壊す | 成功条件 5 そのもの |

**「LLM に送るなら埋め込みも送ってよい」とはしない。**

## 検討した代替案

**埋め込み API** — 精度・手軽さは勝るが `C-01` に反する。却下。

**Cloudflare Vectorize** — クラウド照合は楽だがベクトルの外部恒久保存は不可。粗い照合は ADR-0004 のプロフィールで代替。

**ハイブリッド** — 初期は過剰。将来再検討可。

## 帰結

**良い点**: `C-01` を構造的に守れる。オフライン検索可。埋め込み費用ゼロ。

**悪い点**: モデル DL（1〜2GB 級）。初回待ち。商用 API より精度が劣る可能性。
